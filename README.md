## 岗位定位
这个岗位干什么
我们做的是 agent infrastructure harness——agent 上下文里装什么、怎么压缩、什么时候注入、什么时候换掉;agent 之间用什么协议通信;记忆和检索怎么接进来。这一层目前没什么人在认真做，大家注意力都在基础模型上。但 agent 真正能不能干活，大半取决于这一层。基础模型和外部 agent 越强，这一层就越值钱——我们被它们抬高，不会被它们冲掉。
未来会做post-training。
我们要什么样的人
对 agent 系统有自己的观点。不是论文里看来的观点，是自己搭过、踩过、改过之后形成的观点。
以下要求不需要全部满足——任一方向深入到能给我们带来新的判断，我们就愿意聊。
